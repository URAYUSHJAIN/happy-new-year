# 🎉 Happy New Year 2026! 🎊

A beautiful and interactive New Year celebration webpage with fireworks, animations, and festive wishes!

## ✨ Features

- **Stunning Animations**: Smooth fade-in and glow effects
- **Interactive Fireworks**: Click the celebrate button for a fireworks show
- **Confetti Celebration**: Beautiful confetti animation
- **Responsive Design**: Works perfectly on all devices
- **Mouse Interaction**: Sparkle effects that follow your cursor
- **Auto Fireworks**: Periodic fireworks display automatically

## 🚀 Quick Start

Simply open `index.html` in your web browser to view the New Year celebration page!

```bash
# Clone the repository
git clone https://github.com/URAYUSHJAIN/happy-new-year.git

# Navigate to the directory
cd happy-new-year

# Open in your browser
open index.html  # Mac
start index.html # Windows
xdg-open index.html # Linux
```

## 🎨 Customization

Feel free to customize the page:
- Change colors in `style.css`
- Adjust animation speeds and effects
- Modify the greeting messages in `index.html`
- Add your own features in `script.js`
